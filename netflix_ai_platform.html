◈ ABOUT THE PROJECT

Intelligent Cinema Analytics Engine

CineAI is a next-generation movie intelligence platform powered by machine learning algorithms trained on the official Netflix Prize Dataset — one of the most significant collaborative filtering datasets in the history of recommendation systems.

The platform processes 17,427 movies released between 1896 and 2005, using advanced content-based filtering and semantic analysis to deliver personalized, AI-driven movie recommendations with production-grade accuracy.

  • Netflix Prize Dataset (17,427 curated titles)
  • Content-Based + Collaborative Filtering hybrid engine
  • TF-IDF Vectorization + Cosine Similarity algorithm
  • Real-time Claude AI natural language recommendations
  • Temporal trend analysis across 110 years of cinema
  • Pandas + NumPy accelerated data processing pipeline
